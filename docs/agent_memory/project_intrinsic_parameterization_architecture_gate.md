Worklog 99's pre-fit parameter-domain validator had two confounds: local Jacobian neighbors came from a fresh UV-space kNN (not the same continuously-supported source-graph adjacency Worklog 98 already validated), and orientation was compared against an independently-signed PCA/support normal (not the synchronized Worklog 98 frame, so a single whole-chart orientation flip -- gauge-equivalent, not a fold -- was mis-scored). Both fixed in place inside `osn_gs/surface/torch_parametric_domain_validity.py` (no separate diagnostic worklog): local Jacobians now use the component's own `tree_edges` ∪ `holonomy_edges` graph, orientation reference is `n_sync = normalize(e_u x e_v)`, and a single global determinant-sign flip is canonicalized before any local fold is declared (fold = disagreement with an IMMEDIATE source-graph neighbor's sign, not a majority vote -- majority-vote diluted the boundary signal in testing).

New `torch_latent_surface_edge_differential.py`: builds a symmetric per-edge differential (`du_ij`, `dv_ij`) from BOTH endpoints' synchronized frames (transport + sign-align + average), for every continuously-supported edge, with a fixed deterministic weight (`(median_spacing/edge_length)^2`, clamped). New `torch_global_differential_uv_integration.py` (candidate B): one weighted least-squares solve over ALL edges simultaneously (u and v decouple into two independent linear systems), single-point gauge fix only. New `torch_orientation_preserving_uv_integration.py` (candidate C): initialized STRICTLY from B, fixed 3-iteration IRLS-style boost of fold-adjacent edge weights, fails closed (`not_globally_parameterizable_at_current_scale`) if folds remain after the fixed schedule -- never PCA-repaired.

Real 7-region paired replay (baseline_compatible 2900/final; same Worklog 98 coherent components): with the corrected validator, tree-integrated UV (A) domain-invalid rate is 67.4% (31/46) -- lower than Worklog 99's confounded 80.4%, confirming the confounds inflated the number, but still a majority. B raised domain-valid only 15->18/46 (+20% relative). **C's domain-valid set matched B's exactly on 46/46 components** -- zero additional components rescued; every component B already solved, C solved in 0 refinement iterations; every component B left folded, C failed closed. B's differential residual stays small (RMS mostly 0.001-0.03) even on domain-invalid components -- folds are not large-residual noise, they are genuine local orientation reversals coexisting with a well-fit global differential solution. NURBS valid_supported is 0.00% for all of A/B/C on both checkpoints.

Decision C: COMPONENT_SCALE_NOT_GLOBALLY_PARAMETERIZABLE. B's modest-only improvement over A rules out "tree integration was the limit" (Decision A). C's zero net rescue beyond B rules out "local injectivity constraint required" (Decision B). The synchronized tangent field (see [[project_synchronized_tangent_frame_curve_lattice]]) is locally coherent (holonomy passes) but a majority of components cannot be globally integrated as one chart at their current scale. Do not add another curve seed. Future decomposition must be driven by intrinsic integrability/chart structure before NURBS fitting -- not NURBS capacity/fitting (see [[project_parametric_patch_architecture_gate]] for the superseded confounded baseline).
