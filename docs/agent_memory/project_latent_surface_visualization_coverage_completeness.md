Worklog 103 correctly exported all 4,599 latent-supported observations as raw point data, but attempted exactly ONE visualization-only NURBS per latent support unit -- 37 of 86 units failed the fixed resolution ladder outright, making those units invisible in the `ALL_LATENT_SURFACES` NURBS overlay even though the underlying supported samples were present. Investigated all 37 real failures directly: every single one was `insufficient_points_for_any_surface` on a unit of size exactly 1 or 2 nodes (a surface fundamentally needs >=3 non-collinear points) -- these are genuinely irreducible isolated fragments produced by the latent support graph itself, not a fitting defect subdivision could rescue.

New `torch_latent_surface_visualization_coverage.py::materialize_unit_with_subdivision`: changes ONLY the visualization unit, never the latent surface, estimator thresholds, support connectivity, chart construction, UV parameterization, or production fitting. On failure, deterministically splits a unit using ONLY its own continuously-supported graph connectivity (farthest-pair BFS anchors, nearest-anchor assignment, then real connected-component analysis on each half -- never convex hull/bounding-box/PCA-rectangle/arbitrary bridging), recursing until success or a minimum-size floor (3), at which point the fragment is reported as `UNREPRESENTED_LATENT_FRAGMENT` with exact source node IDs and reason. Found and fixed a real bug during testing: the recursion originally tried a whole-piece fit BEFORE checking whether the piece was already internally disconnected -- since the LSQ fitter doesn't care about connectivity and can numerically "succeed" on any point cloud, this could silently produce one NURBS spanning two never-connected pieces. Fixed by always running connected-component analysis first, splitting immediately if the piece isn't a single component, and only ever attempting a fit on a genuinely connected piece.

Real 7-region regeneration (checkpoint `baseline_compatible/final`, separate output directory from Worklog 103 so before/after stays comparable): 4,539/4,599 latent-supported nodes (98.7%) now represented by a visualization NURBS (up from unit-level 49/86), remaining 60 nodes (1.3%) explicitly listed as unrepresented fragments -- all the same 1-2-node isolated pieces the failure investigation found. Visualization NURBS patch count rose 49->59. `node_accounting_ok` (every latent-supported node ends up in exactly one materialized-or-unrepresented bucket, no silent loss) verified `true` for all 7 regions mechanically.

**This worklog makes NO qualitative/architecture conclusion**, same as Worklog 103 -- the completion condition ("every Worklog 103 latent-supported observation is either visibly represented or explicitly marked unrepresented with a factual reason") is now mechanically satisfied, so the `ALL_LATENT_SURFACES` view is ready for the user's own qualitative review.
