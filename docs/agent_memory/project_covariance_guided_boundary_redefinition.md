**What this is.** A user-directed canonical redefinition of what "boundary" means for the isolated Boundary-first NURBS work, layered ON TOP of (not replacing) [[project_boundary_first_isolated_topology_rebuild]]'s existing support/control/NURBS construction contract (worklogs 110/112: review geometry semantics, support-crossing gate, star-shape anchor correspondence — all kept unchanged). The thing being redesigned is the UPSTREAM boundary-evidence-extraction step that currently feeds that contract.

**Why this exists.** In a complex scene, distance-based connectivity can make every Gaussian look like one giant connected component. So boundary must NOT be defined as: the outline of the whole Gaussian distribution, a Euclidean connected component's outline, a single-PCA-UV KDE-mask contour, a bounding box, or a voxel component's outline. Canonical definition instead: **boundary is where Gaussian adjacency that could continue as the same surface manifold breaks, per observation + geometry + covariance evidence.**

**Core distinguishing principle:** observation status and geometric reliability are different axes. An observed Gaussian is NOT automatically reliable surface evidence — isolated floaters, isotropic blobs, and oversized "bridge" Gaussians can all be observed while contributing nothing (or misleading) structural evidence.

**Target long-term pipeline (not fully built yet — see scope below):**
```
Observed Gaussians -> covariance eigenframe extraction -> structural reliability estimation
  -> covariance-guided surface adjacency graph -> manifold-consistent local surface sheets
  -> world-space boundary half-edge graph -> ordered boundary chains/loops
  -> chart-local UV representation -> common Boundary-first NURBS construction (existing, unchanged)
```

**KDE/raster/marching-squares is NOT deleted**, just demoted: kept for local support regularization, density-gap/false-hole diagnostic, local contour proposal, noise suppression, visualization, and as a secondary-validation baseline against the new covariance-guided path. Metadata convention specified (not yet actually inserted into the existing code): legacy path gets `extraction_mode=raster_assisted_legacy`/`evidence_level=secondary`/`canonical_boundary_source=false`; new path gets `extraction_mode=covariance_guided_manifold`/`evidence_level=primary_candidate`/`canonical_boundary_source=pending_gate`. Never auto-promoted to canonical/default without separate user approval.

**Scope actually implemented this round (first foundation only, per user's own explicit phasing — NOT full production algorithm):**

- **Module A — `osn_gs/surface/torch_gaussian_covariance_frame.py`:** `extract_covariance_frame()` eigen-decomposes `(N,3,3)` covariance (via `torch.linalg.eigh`, forced symmetric, descending eigenvalues). `eigenvector(lambda3)` = normal candidate, other two = tangent candidates. Shape classification into `planar_surfel`/`needle_like`/`isotropic`/`ambiguous_shape` via configurable ratio thresholds (not canonical-final). `orientation_insensitive_alignment(a,b) = abs(dot(a,b))` used everywhere pairwise since eigenvector sign is ambiguous — eigenvector sign is never treated as a physical outward normal. `covariance_from_scale_rotation()` is a small self-contained `R diag(s^2) R^T` builder for fixtures/tests, deliberately NOT importing `osn_gs.gaussian.torch_model` (keeps this fully isolated).
- **Module B — `osn_gs/surface/torch_gaussian_structural_reliability.py`:** per-Gaussian classification into `reliable_structural_evidence`/`ambiguous_structural_evidence`/`rejected_structural_evidence` from 5 independent scored axes (planarity, k-NN neighbor normal agreement, BIDIRECTIONAL mutual tangent-plane residual — both directions required per instruction, not just one, scale consistency vs. neighborhood median, local support/density). Every component score + failed-axis reasons preserved in provenance, never collapsed to one scalar.
  - **Real bug found and fixed:** first `local_support_score` formula (`exp(-normalized_mean_neighbor_distance/3.0)`) made even a perfectly clean, densely-tiled flat plane score below the 0.4 reliable threshold (all 81 Gaussians came out `ambiguous` instead of `reliable` — caught because the plane-scene test explicitly requires 100% reliable). Root cause: exponential decay too aggressive for a normal touching-footprint grid spacing. Fixed by switching to a piecewise-linear ramp (`close_ratio=1.0` -> score 1.0, `far_ratio=10.0` -> score 0.0) which cleanly separates a normal tiled plane (ratio ~2.9, score ~0.8) from a truly isolated floater (ratio ~60, score 0).
- **Module C(+E) — `osn_gs/surface/torch_gaussian_manifold_affinity.py`:** pairwise same-surface adjacency graph over k-NN candidate edges only (never pure-distance). **Key design decision, arrived at after a second real bug:** edge classification computes FRESH pairwise metrics for the specific candidate pair (i,j), never reusing Module B's whole-neighborhood-AVERAGED reliability score for that decision. First attempt gated `crease_or_orientation_discontinuity` on both endpoints having "high" confidence (derived from the averaged reliability class) — this silently broke the required "perpendicular wall/floor -> crease" test, because Gaussians sitting exactly at a real crease are the ones whose neighborhood-averaged reliability gets pulled down the most (their k-NN includes the other surface's contradictory normals) — so requiring high confidence made crease undetectable exactly where it matters. Fixed by dropping the confidence gate on crease entirely (only a REJECTED endpoint hard-blocks any edge; "ambiguous" endpoints can still form `same_surface`/`crease` edges based on pairwise geometry alone). Six edge states: `same_surface`, `crease_or_orientation_discontinuity`, `parallel_but_separate`, `proximity_only`, `ambiguous`, `rejected` — never a single boolean. Also ships a light, explicitly-EXPERIMENTAL `classify_node_boundary_status()` (interior_continuation/crease_boundary_candidate/observed_support_boundary_candidate/unresolved_boundary) built directly from the same_surface/crease edge set — NOT an ordered world-space half-edge/loop graph (that's explicitly deferred, matches the user's own scope limit for this round).
- **Module D — `nurbs_constructor_benchmark/gaussian_reliability_scenes.py`:** 7 synthetic covariance-bearing scenes (`plane`, `two_perpendicular_surfaces`, `close_parallel_sheets`, `smooth_curved_sheet`, `isolated_floater`, `isotropic_blob`, `oversized_bridge`) returning explicit `(positions, covariances)` pairs — a NEW benchmark-scenes file parallel to (but distinct from) `nurbs_constructor_benchmark/scenes.py` (which is point-cloud-only, no covariance). Anomaly scenes are built by injecting one anomalous Gaussian into a clean base scene (floater/isotropic-blob/bridge), which made per-group-label assertions easy to write.

**Confirmed end-to-end behavior across all 7 scenes (this is the actual validation, not just unit-level):** clean plane and smooth curved sheet = 100% reliable, same_surface-only graphs. Perpendicular wall/floor = fully separated same_surface regions with `crease_or_orientation_discontinuity` (never `same_surface`) at the seam. Close parallel sheets = fully separated same_surface regions with `parallel_but_separate`/`rejected` (never `same_surface`) between them. Isolated floater = correctly `rejected` + `proximity_only` (too far to even be a candidate). Isotropic-blob Gaussians = correctly `rejected`, their immediate neighbors correctly downgraded to `ambiguous` (real uncertainty propagation, not a bug). Oversized bridge Gaussian in the floor/wall gap = correctly `rejected`, zero `same_surface` edges to either real surface (does not bridge them). BFS-connectivity test confirms one unreliable floater doesn't fragment the otherwise-fully-connected reliable plane region.

## Round 2 — Worklog 115, Reliability/Affinity Robustness Hardening (2026-07-29)

User asked for "Worklog 114" but a concurrent Codex session had already claimed it (`114_trimmed_component_jacobian_test_health.md` — that session also independently fixed the repo's 2 pre-existing `test_trimmed_component_fitter.py` failures, not this thread). Landed on **115**.

**Purpose:** harden worklog 113's foundation (state contract, scale normalization, candidate graph, invariance, failure modes) so it's robust enough for complex-scene surface-region formation — explicitly NOT connecting it to the boundary extractor, existing builder, dispatcher, or trainer yet.

**Key structural change:** `torch_gaussian_structural_reliability.py` split single-axis reliability into `IntrinsicStructuralReliability` (covariance-only, no neighbor dependency) and `ContextualManifoldConsistency` (neighbor-dependent). This is what lets a crease Gaussian be `intrinsic_reliable + contextual_mixed` instead of collapsing into the same bucket as a genuinely bad (isotropic/degenerate) Gaussian. `torch_gaussian_manifold_affinity.py` replaced the single `edge_state` with 4 orthogonal axes (candidate_status, endpoint_status, manifold_relation, relation_confidence) and added 10 independently-recorded pairwise metrics — old `.state`/`EDGE_*` kept as a compatibility projection (with a `not_evaluated -> proximity_only` mapping added, since without it 2 of worklog 113's own tests broke).

**Two real bugs found and fixed this round:**
1. Candidate-degree cap (`max_candidate_count_per_node`) was applied by walking positional array index order, so which candidates got capped depended on input array order — violated input-order-determinism (§8 gate). Fixed by sorting scale-backed candidates by `(distance, stable_id_pair)` before applying the cap. Verified 0 mismatches across 10 random shuffles, keyed by stable id.
2. (Attempted then reverted) added a same_surface exclusion gate on `normal_direction_separation_over_thickness` to fix a close-parallel-sheets threshold anomaly (gap=0.02 sweep value had 19/224 cross-label edges wrongly `same_surface`) — this broke `smooth_curved_sheet` (1 region -> 2 regions), because that metric and `mutual_tangent_residual` are the SAME physical offset normalized by different denominators (ratio is a near-constant ~25x, since normal_thickness << tangent_major_scale by construction), so it can't distinguish "real gap between flat surfaces" from "curvature-induced offset over a few grid steps" without also knowing tangential distance. Reverted; documented gap=0.02 as a genuine, disclosed threshold-sensitive transition zone instead of chasing an unstable fix. **Lesson: when two metrics are literally the same measurement under different normalization, adding a threshold on one as an "independent" check can silently reintroduce the same brittleness in a different scale, especially for curvature/periodic fixtures — verify against a scene requiring the OPPOSITE behavior before accepting a new guard.**

**Validated via targeted re-analysis (not just re-asserted):** the worklog 113 finding "isotropic-blob's 4 neighbors became ambiguous" was directly compared across 5 aggregation methods (mean/median/trimmed_mean/reliability_weighted/rejected_excluded) on the same fixture — mean contaminates 10/79 plane neighbors, trimmed_mean 4/79, median and reliability_weighted and rejected_excluded all 0/79. Kept `rejected_excluded` as default (not just because it "works" but because it's the most interpretable: it excludes exactly the neighbors that were independently judged INTRINSICALLY_REJECTED, unlike median's purely statistical robustness).

**Real trained Gaussian diagnostic actually ran** (not "not_available"): found `output/osn_gs_ab_3k/final/point_cloud.ply` (2.19M Gaussians, from the existing baseline-3DGS-comparison training run already in the repo, no new download/training). A uniform random subsample destroys local density (93% of candidates become outside_candidate_support) — had to use a spatially-localized crop (nearest 4000 to scene centroid) to get a meaningful candidate graph. Real-scene distribution is much noisier than synthetic fixtures (majority `ambiguous`, substantial `parallel_but_separate` from thin/duplicate structure) — this is disclosed as an observation, not a claim that current thresholds are tuned for real data.

**Known disclosed limits carried forward (not fixed, not claimed fixed):** gap=0.02 close-parallel threshold-sensitivity; curvature-sweep phase-aliasing at higher amplitude (two non-adjacent points on a periodic curved sheet can look locally identical to a pure pairwise check — would need path-connectivity or consensus-based region merging to resolve, explicitly out of scope this round).
