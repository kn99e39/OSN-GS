Worklog 98 replaces Worklog 96's per-seed independent transversal-direction selection (the root cause of Worklog 97's 91.7% parameterization failure) with one globally synchronized in-plane tangent frame field over the latent surface. Visible Gaussian training, ADC, region ownership, Worklog 95's estimator, supported-query semantics, continuous-support requirements, existing seed provenance, NURBS degree (2), 6x6 control grid, Worklog 97's external-UV/native fitting, and held-out/safety criteria are all fixed and unmodified.

New modules:
- `osn_gs/surface/torch_latent_surface_tangent_frame_field.py`: the latent-surface estimator's local PCA axes supply ONLY the tangent plane (normal), never an authoritative in-plane direction. Builds a k=16 (Worklog 95's own `DEFAULT_K`) kNN graph over region train evidence, every edge validated by continuous-support. Per topological component: pick an anchor (typed seed's own tangent if available, else geometric centroid-nearest, deterministic), then propagate `(e_u, e_v)` via a **3D-distance Dijkstra spanning tree** (not raw BFS hop-count -- measured that BFS produces materially larger path-dependent drift under rotation; this was a legitimate correctness fix, not a tuned threshold) using `propagate_tangent_onto_plane` (reused from Worklog 96's tracer) at every parent->child step -- never independently re-picked. Tree-edge chord-length integration gives every node a `(u, v)` potential. Every non-tree (cycle-closing) edge is checked for holonomy: propagate one endpoint's `e_u` across the edge and compare cosine similarity to the other endpoint's already-assigned `e_u` (same cosine<=0 floor as Worklog 97) -- ANY inconsistent cycle edge marks the whole component incoherent (fail-closed, never PCA-repaired). Frame-propagation singularities (near-parallel transport) halt expansion at that node, producing natural pre-fit decomposition.
- `osn_gs/surface/torch_latent_surface_curve_lattice.py`: traces U/V integral curves from the synchronized field (direction looked up from the nearest field node each step, never re-selected), but the actual fit input is the full coherent component's field-derived `(u, v)` (a consistent superset of the traced curves).
- `osn_gs/surface/torch_curve_lattice_native_fit.py`: feeds the lattice into Worklog 97's unchanged `fit_torch_visible_surface_from_uv` (no PCA).
- Replay `scripts/devtools/synchronized_frame_lattice_replay.py`: paired, no-fallback A (Worklog96+PCA-UV) / B (Worklog96 independent-direction+Worklog97 native) / C (new synchronized field+native) comparison on identical region evidence.

Real 7-region replay (baseline_compatible checkpoints 2900, final): **B's `inconsistent_transversal_curve_direction` failure rate (raw component count) drops from combined 91.67% (11/12 blocks) to C's 30.30% (20/66 components)** -- 17.14% (6/35) at 2900, 45.16% (14/31) at final. (Correction: the original writeup conflated this raw component-count rate with the evidence-weighted `parameterization_invalid` fraction -- 20.42% at 2900, 50.08% at final -- a different metric; both are now reported separately.) C also produces far more patch candidates (66 components vs. Worklog 96's 12 seeds) since one global field naturally decomposes into multiple coherent regions. However, even conditional on successful parameterization (evidence-weighted basis), the fixed 6x6 degree-2 NURBS remains predominantly extrapolative/unsafe: conditional valid_supported is only 7.1% (2900) and 4.8% (final). C's raw valid_supported is inconsistent vs. baseline A (5.67% > A's 3.41% at 2900, but 2.38% < A's 13.96% at final) -- no consistent improvement. Extrapolative+unsafe combined is lower for C than A at both checkpoints (73.9% vs 96.6% at 2900; 47.5% vs 86.0% at final).

Scope correction: this batch does NOT prove the NURBS representation itself is already the bottleneck. What it establishes is narrower: (1) latent-surface support is available, (2) curve construction is broadly available, (3) globally synchronized tangent orientation substantially resolves Worklog 97's independent-direction failure, (4) but the current synchronized-field -> tree-integrated-UV -> fixed 6x6 degree-2 tensor-product LSQ NURBS path still produces predominantly extrapolative/unsafe patches even on parameterization-valid components. Worklog 98 does not make a final architecture decision by itself -- attributing the remaining failure to patch representation vs. fixed capacity vs. generic LSQ fitting vs. UV-construction quality is the next bounded batch's task. See [[project_curve_network_native_nurbs_fitting]] for the Worklog 97 baseline this replaces the direction-selection mechanism of.
