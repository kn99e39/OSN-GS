- [Worklog 98: 전역 동기화 tangent frame 기반 curve lattice](98_synchronized_tangent_frame_curve_lattice.md)
  - Worklog 96의 per-seed 독립 transversal 방향 선택을 latent surface 위 전역 동기화 tangent frame field로 대체했다. 신규 `torch_latent_surface_tangent_frame_field.py`: local PCA tangent axis는 tangent plane(normal)만 제공하고 in-plane 방향으로 쓰지 않는다. Region train evidence에 Worklog 95의 k=16 kNN(계속 지지 검증됨) 그래프를 만들고, 각 topological component마다 anchor(typed seed가 있으면 그 접선, 없으면 centroid-최근접 결정론적 선택)에서 **3D 거리 기준 Dijkstra**(BFS hop-count의 path-dependent drift를 실측으로 확인 후 정정) spanning tree로 frame을 parallel-transport 전이하며 chord-length `(u,v)` potential을 tree edge 적분으로 부여한다. Cycle-closing edge마다 전이된 frame과 실제 frame의 cosine을 검사해(Worklog 97과 동일 cosine≤0 고정 기준) holonomy 불일치가 하나라도 있으면 그 component 전체를 fail-closed한다(PCA 복구 없음). 신규 `torch_latent_surface_curve_lattice.py`는 동기화된 field에서 U/V integral curve를 추적하되 매 step 방향을 가장 가까운 field node에서 조회한다(독립 재선택 없음); 실제 fit 입력은 이미 holonomy 검증을 통과한 coherent component 전체의 `(u,v)`다. 신규 `torch_curve_lattice_native_fit.py`가 Worklog 97의 `fit_torch_visible_surface_from_uv`를 그대로 재사용한다. 신규 `synchronized_frame_lattice_replay.py`가 A(Worklog96+PCA)/B(Worklog97 독립방향+native)/C(신규 동기화+native) 3-way paired 비교를 fallback 없이 실행한다. **실측(component 개수 기준, 후속 정정): B의 `inconsistent_transversal_curve_direction` 실패율이 91.67%(11/12 block)에서 C의 30.30%(20/66 component)로 크게 줄고, patch candidate 수도 12→66개로 늘었다.** 그러나 parameterization이 성공한 component만 조건부로 봐도(evidence-weighted 기준) 최종 6×6 degree-2 NURBS는 여전히 압도적으로 extrapolative/unsafe다(조건부 valid_supported 4.8~7.1%뿐이고, C의 valid_supported는 checkpoint마다 A보다 낫거나(2900: 5.67% vs 3.41%) 못하다(final: 2.38% vs 13.96%) — 일관된 개선이 아님). **범위를 좁힌 결론(정정)**: latent-surface support 확보·curve construction 널리 가능·전역 동기화 방향이 Worklog 97 실패를 상당 부분 해소 — 이 세 가지만 확정하며, NURBS representation 자체가 이미 병목으로 증명됐다고 단정하지 않는다(원래 "Decision B: PARAMETRIC_PATCH_MODEL_LIMIT" 문구는 과도한 일반화였음을 후속 정정). 신규 focused 테스트 19개 + 관련 기존 168개 전부 통과, 전체 regression 1036 passed 1 skipped, curve-seed heuristic 추가 없음, 또 다른 고립 진단으로 잇지 않음.

- [Worklog 99: bounded parametric patch architecture gate](99_parametric_patch_architecture_gate.md)
  - Worklog 98의 orientation-coherent component가 실제로 well-conditioned parameter domain인지 fitting 이전에 검증하고, A(고정 6×6 LSQ)/B(adaptive capacity NURBS)/C(Gordon-style curve-network)를 fallback 없이 paired 비교했다. 신규 `torch_parametric_domain_validity.py`: UV-공간 local kNN에 least-squares affine Jacobian을 적합해 orientation reversal/foldover(Jacobian 두 열 외적을 실제 normal과 비교)·singularity·extreme stretching(condition number, local spacing 대비)·duplicate-UV-incompatible-geometry를 검출하고, Worklog 98의 기존 holonomy edge로 position 기준 cycle drift도 진단한다. 신규 `torch_adaptive_nurbs_capacity.py`: capacity를 Worklog 98 자신의 U/V curve 개수·sample 수·aspect ratio로만(fit/held-out 오차 전혀 사용 안 함, AST로 확인) 결정해 기존 `fit_torch_visible_surface_from_uv`(이미 second-difference 정규화 내장)에 그대로 넘긴다. 신규 `torch_gordon_curve_network_surface.py`: 고전 Gordon transfinite interpolation(`S1+S2-S12`)을 discrete U/V level에 실제 quadratic curve를 least-squares fit해 근사하고, 두 family 독립 fit의 intersection 불일치를 residual로 report하며, 채워진 level이 부족하면 fail-closed한다(가짜 boundary 없음). **실측(checkpoint 2900/final, 7-region): orientation-coherent component의 combined 80.4%(37/46)가 A/B/C 비교 이전에 이미 UV fold/orientation reversal로 무효**(2900: 75.9%, final: 88.2%, 두 checkpoint 모두 원인 100% foldover).
